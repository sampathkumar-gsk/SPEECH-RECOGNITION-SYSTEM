Description:

A Speech Recognition System was designed using Arduino UNO to control an LED using command-based input. In this project, commands such as ON and OFF are sent through serial communication to simulate speech recognition functionality. The Arduino processes the received command and controls the LED accordingly. Tinkercad was used for circuit simulation and Arduino IDE was used for programming. This project demonstrates the basic working principle of voice-controlled automation systems used in smart homes and IoT applications.
